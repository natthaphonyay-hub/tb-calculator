# TB Calculator

เครื่องมือช่วยเภสัชกรคิดขนาดยาวัณโรคสูตร 2HRZE/4HR สำหรับผู้ใหญ่ (อายุมากกว่า 15 ปี) ตามน้ำหนัก มี 2 หน้า

1. **เริ่มยาใหม่** กรอกอายุ น้ำหนักก่อนเริ่มรักษา วันเริ่มยา ได้ขนาดยาแต่ละตัว จำนวนเม็ด มก./กก. ช่วงวันที่ของแต่ละระยะ นัดติดตาม รายการตรวจก่อนเริ่มยา Pharmacist note และข้อความตอบพยาบาล
2. **ปรับยาตามน้ำหนัก** กรอกน้ำหนักเดิม น้ำหนักใหม่ ระยะที่กินอยู่ จอบอกว่า "ปรับยา" หรือ "ไม่ต้องปรับยา" พร้อมขนาดใหม่ของตัวที่เปลี่ยน

ดูตัวอย่าง: เปิด `index.html?example=1` (หน้าเริ่มยา) หรือ `index.html?example=adjust` (หน้าปรับยา)

## หลักของเครื่องมือ

ช่วยไกด์ ไม่ตัดสินแทน ไม่บังคับ แต่เตือน: จอเสนอขนาดตามมาตรฐานก่อน เภสัชแก้จำนวนเม็ดเองได้ทุกตัว ขนาดที่หลุดมาตรฐานขึ้นป้ายเตือน (แดง เกินขนาดสูงสุด, เหลือง สูงกว่าช่วง, ฟ้า ต่ำกว่าช่วง) แต่ไม่ห้ามกดต่อ ขนาดที่เภสัชแก้มีวงเล็บ "(เภสัชปรับจากตาราง)" ใน note ข้อยกเว้นเดียวคืออายุ 15 ปีลงมา จอไม่แสดงขนาด เพราะเครื่องมือไม่มีข้อมูลขนาดยาเด็ก

## ที่มาของตัวเลข

- ขนาดยาตามน้ำหนัก: แนวทางการควบคุมวัณโรคประเทศไทย พ.ศ. 2564 กองวัณโรค ตาราง 5.1 หน้า 60 (ตัดแถวที่ 50 และ 70 กก. พอดี) น้อยกว่า 35 กก. คำนวณตามน้ำหนัก (หมายเหตุตาราง 5.1) เป้า H 5 R 10 Z 25 มก./กก. (กึ่งกลางช่วงในหัวตาราง) E 15 มก./กก. (หน้า 62)
- ขนาดสูงสุด: H 300 R 600 มก. (ค่าสูงสุดในตาราง 5.1) Z 2,000 E 1,600 มก. (WHO operational handbook Module 4 DS-TB 2022 ภาคผนวก หน้า 50)
- นัดติดตาม: ตาราง 5.3 หน้า 63-64 · ผู้ป่วยตั้งครรภ์ใช้น้ำหนักก่อนตั้งครรภ์: หน้า 69
- ขนาดเม็ดตั้งต้น: เม็ดเดี่ยว H 100, R 300 และ 450, Z 500, E 400 และ 500 มก.
- ข้อมูลยาและกติกาอยู่ใน `index.html` ระหว่าง `DATA-START` กับ `DATA-END` ตัวคำนวณอยู่ระหว่าง `CALC-START` กับ `CALC-END`

## ทดสอบ

```
node tests/test-calc.mjs          # ชุดทดสอบตัวคำนวณและข้อความ note ทั้งฉบับ
python3 -I tests/fuzz.py 40000    # สุ่มเทียบกับตัวคำนวณแยก tests/reference.py (เขียนจากสเปกอย่างเดียว ใช้เลขเศษส่วน)
node tests/e2e-ui.mjs             # กดหน้าเว็บจริงใน Chrome ทุกน้ำหนักขอบแถว + สุ่ม ตรวจล้นจอ 300 ถึง 1280 px ภาพจออยู่ tmp/shots/
node tests/make-hand-check.mjs    # สร้าง docs/ตารางตรวจมือ-การคำนวณ.md ไว้กดเครื่องคิดเลขตาม
```
